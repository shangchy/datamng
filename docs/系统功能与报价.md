## 二、功能清单（已实现）

### 1. 登录 / 权限 / 日志
- JWT 登录、角色权限（菜单级）、账户管理、修改/重置密码
- 操作日志、文件日志（按天轮转）

### 2. 订单管理
- 订单 CRUD、Excel 导入（按订单号去重 / 更新）、导出（日期 MMDD）
- 验重（在执订单：运营商 + URL 集合 + 地区集合完全一致才算重复）
- 状态全流程：未提 → 在执 → 改单 / 待停 → 已停
- 停单（单条 / 批量，选日期 + 原因）、批量删除、批量改小组
- 回执导入（按 任务名 + 甲方 + 运营商 + 渠道 匹配工单号，排除已停）
- 订单模版下载、改单表 106 拓展码填充
- 导入状态完全按 Excel「状态」列映射

### 3. 客户管理
- 客户 CRUD、合作起止日期、备注、预警额度
- 充值（U / 人民币双向换算，汇率可配置，默认 6.7）
- 渠道单价维护
- **账单模版配置**（选择「账单」类型模版）
- 订单记录（关联一级代理 / 甲方 / 二级代理）

### 4. 基础数据
- 品类（一 / 二级）、渠道、运营商、平台、配件（URL）、小组 / 代理

### 5. 日活数据
- 导入（**同任务内手机号去重**、按工单号关联订单、平台自动关联品类、洗名库自动补姓名）
- 导出、清空、批量删除

### 6. 分数据
- 按小组分组、出数模版生成文件、按一级代理建文件夹
- 生成各代理账单（**按客户配置的账单模版**，自动插行并保留样式）
- 校验（出数模版 / 小组 / 代理一致性）、软确认

### 7. 洗名
- 洗名库维护（手机号 → 姓名 / 省 / 市 / 运营商）
- 导出 / 导入洗名（Excel 闭环，不覆盖已有省市区）

### 8. 账单管理
- 账单列表、账单详情（小组明细）、清空
- 账单导入（读取「余额总览」sheet，按编号更新客户余额 + 账单）

### 9. 预警中心
- 停单提醒（**预警天数可配置**，提前 N 天提醒）
- 账单预警（余额低于预警额度）
- 定时扫描 + 触发时间配置 + 手动执行

### 10. 模版管理
- 模版文件（**类型：订单 / 出数 / 账单 / 其他**）、模版名称 / 编号
- 上传 / 预览 / 下载 / 删除

### 11. 提单管理
- 提单表 / 改单表 / 停单表生成（按规则选模版）
- 提单确认、提单历史

### 12. 看板 / AI
- Dashboard 基础看板
- AI 助手（DeepSeek 集成）

### 13. 部署
- GitHub Actions 打包构建（前端构建 + 打包 Windows 部署包）
- Windows run.bat 一键启动（自动创建 venv、装依赖）

## 三、标准报价

按国内软件外包行业惯例，以「人日」为工作量单位估算。

### 工作量估算

| 模块 | 人日 |
|---|---|
| 需求分析 + 数据库设计（27 表） | 4 |
| 登录 / 权限 / 日志 | 2 |
| 订单管理（导入 / 验重 / 回执 / 停单 / 提单 / 改单） | 10 |
| 客户管理（充值汇率 / 单价 / 账单模版） | 4 |
| 基础数据 | 3 |
| 日活数据 + 去重 + 洗名库 | 5 |
| 分数据 + 账单生成（模版填充 / 插行） | 6 |
| 账单管理 + 账单导入 | 3 |
| 预警中心（扫描 / 天数配置） | 3 |
| 模版管理 + 提单表生成 | 6 |
| 看板 + AI 助手 | 3 |
| 部署打包 + 文档 | 3 |
| **合计** | **52** |

- 需求反复沟通 / 返工上浮 20–30% → 实际约 **62–68 人日**。

### 换算金额（常见单价）

| 档位 | 单价（元/人日） | 对应金额 |
|---|---|---|
| 中高级个人全栈 | 800–1,200 | 5万–8万 |
| 外包团队 / 工作室 | 1,500–2,000 | 9万–13.5万 |
| 正规软件公司 | 2,000–3,000 | 12.5万–20万 |

> 说明：报价按「交付物价值 + 市场行情」锚定，而非按生产方式（是否使用 AI）打折。
