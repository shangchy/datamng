# LM 订单管理系统 · 功能清单、功能说明与标准报价

> 版本：2026-10-07
> 用途：供他人对系统功能与商业价值进行报价评估参考。
> 使用对象：个人用户（单机 / 轻量部署）。

---

## 一、系统概览

LM 订单管理系统是一套面向「数据获客 / 渠道分发」业务场景的一体化管理系统，覆盖订单、日活数据、分数据、洗名、公积金、账单、客户、预警、AI 助手等完整业务闭环。

- 技术栈：Python / FastAPI + SQLAlchemy（PostgreSQL / SQLite），React 18 + Vite 前端。
- 部署：支持 Windows 一键启动（SQLite 免安装）；本地开发用 PostgreSQL。
- 账号体系：多角色权限（超级管理员 / 运营 / 财务 / 只读）+ 菜单级权限控制。

### 系统规模

| 指标 | 数值 |
|---|---|
| 后端 + 前端代码量 | 约 12,300 行（后端 8,078 / 前端 4,210） |
| API 接口数 | 136 个 |
| 数据模型 / 表 | 27 张 |
| 后端路由模块 | 11 个（auth / users / customers / orders / master / data / dashboard / ai / order_templates / templates / logs） |
| 前端页面 | 10 个 |
| AI 助手工具 | 17 个只读查询工具 |

## 二、功能清单与功能说明

### 1. 登录 / 权限 / 日志

| 功能 | 说明 |
|---|---|
| 账号登录 | JWT 鉴权，默认账号 admin / 密码可改 |
| 角色权限 | 4 种角色 + 6 组菜单级权限（订单/数据/客户/基础/账单/预警），管理员拥有全部权限 |
| 账户管理 | 用户增删改查、重置 / 设置密码、角色与权限分配 |
| 操作日志 | 记录关键操作（登录、增删改等） |
| 运行日志 | 文件日志按天轮转 |

### 2. 工作台（Dashboard）

| 功能 | 说明 |
|---|---|
| 经营概览 | 今日 / 指定日营业额、利润、进货量、在执订单数、待处理预警数 |
| 趋势图 | 营业额 / 利润 / 进货量（按交付量口径）时间趋势 |
| 排行 | 代理营业额 / 利润排行 |
| 分布饼图 | 一级品类 / 二级品类 / 渠道数据量分布 |

### 3. 订单管理

| 功能 | 说明 |
|---|---|
| 订单 CRUD | 新建提单、编辑、改单、删除 |
| 复制新增提单 | 一键复制已有订单生成新单 |
| Excel 导入 | 按订单号去重 / 更新，状态完全按 Excel「状态」列映射 |
| Excel 导出 | 导出订单列表 |
| 验重 | 在执订单重复检查（运营商 + URL 集合 + 地区集合一致才判重），仅提示不拦截 |
| 状态全流程 | 未提 → 在执 → 改单 / 待停 → 已停 |
| 停单 | 单条 / 批量停单（选日期 + 原因），生成停单表 |
| 批量操作 | 批量删除、批量改小组、批量复提（选更新日期） |
| 回执导入 | 按「任务名 + 甲方 + 运营商 + 渠道」匹配工单号，排除已停 |
| 工单号自动生成 | 甲方 = 新 且工单号为空时按规则自动生成 |
| 业务开关字段 | 是否加名、是否撞库（是/否） |
| 平台无二级品类查询 | 快速筛出未挂二级品类的平台订单 |
| 待停订单可编辑 | 待停状态订单也支持改单编辑 |

### 4. 提单管理

| 功能 | 说明 |
|---|---|

| 提单确认 | 更新订单状态（未提/改单 → 在执，待停 → 已停）并写入提单历史 |

### 5. 日活数据

| 时间段查询 | 按数据日期起止范围查询 |
| 级联筛选 | 一级品类 → 二级品类 → 平台、一级代理 → 二级代理/渠道 级联下拉 |
| 列表 | 默认每页 1 万条、整体序号编号、字段排序 |
| 导出 | 支持自定义列导出、无条数上限 |
| 补充品类 | 一键按平台回填缺失的品类 |

## 三、标准报价

按国内软件外包行业惯例，以「人日」为工作量单位估算。

### 工作量估算（按实际投入时间）

| 项目 | 数值 |
|---|---|
| 开发周期 | 2026-09-10 ~ 2026-10-05（26 天） |
| 投入人员 | 1 人 |
| 每日投入 | 6 小时 |
| 总时长 | 26 × 6 = 156 小时 |
| 折合人日（8 小时/人日） | 156 ÷ 8 ≈ 19.5 人日 |

> 说明：本系统采用 **AI 辅助开发**（AI 编程 + 代码生成），开发效率显著提升。同等规模系统若按传统纯人工开发，预估约 40–60 人日；AI 辅助下实际投入仅 156 小时（约 19.5 人日）。上表已按实际投入时间（含 AI 辅助）计算。

### 换算金额（个人对个人）

| 档位 | 单价（元/人日） | 对应金额 |
|---|---|---|
| 个人开发者（个人对个人） | 500–800 | 约 1.0万–1.6万 |

> 说明：按实际投入 156 小时（约 19.5 人日）计，单价 500–800 元/人日 → 9,750–15,600 元。本系统使用对象为个人、双方为个人对个人交易，无公司管理成本 / 税负加成。

## 四、后续可选优化项（待排期）
