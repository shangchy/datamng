# LM订单管理系统 · 页面设计文档

> 依据原型（docs/prototype.html）与数据库设计（docs/db_design.md）整理。
> 本文档描述每个页面的**布局、字段、交互细节、处理逻辑**，作为前端实现依据。

---

## 1. 整体框架

### 1.1 布局
- 左侧固定侧边栏（210px）：系统 Logo + 菜单导航 + 底部账户标识
- 顶部：当前页面标题 + 当前用户（用户名 + 角色徽章 + 退出按钮）
- 内容区：随菜单切换

### 1.2 菜单结构（含权限）
| 菜单 | 权限 |
|---|---|
| 工作台 | 所有 |
| 订单管理 | 所有 |
| 数据管理（分组）→ 日活数据 / 公积金 | 所有 |
| 客户管理 | 所有 |
| 配件管理 | 所有 |
| 品类管理 | 所有 |
| 渠道管理 | 所有 |
| 运营商管理 | 所有 |
| 账单管理 | 所有 |
| 预警中心 | 所有 |
| 账户管理 | 仅超级管理员（`account:*` 权限） |

- 「数据管理」为可展开分组，子项「日活数据」「公积金」；分组默认展开当有子项处于激活态。
- lemon001/lemon002 无 `account:*` 权限，侧边栏不渲染「账户管理」，后端接口同样拦截。

### 1.3 登录
- 用户名 + 密码登录，JWT 鉴权；首次登录/重置后强制改密；连续 5 次失败锁定 15 分钟。

## 2. 通用交互组件

### 2.1 动态列表（通用表格）
所有列表页共用：
- **表头**：由字段字典（COLS）渲染；「⚙ 自定义表头」弹窗勾选显示列、可恢复默认。
- **排序**：点击表头列切换 升序▲ / 降序▼ / 取消。
- **查询条件**：按表头字段自动生成；状态类字段生成下拉（选项=数据去重值），其余生成文本输入；默认显示前 6 个，「更多筛选」展开全部、「收起」恢复。
- **操作列**：文案居中；按钮见各页。
- **双击行**：打开详情（见 2.3）。
- **分页**：底部翻页。

### 2.2 确认弹窗（防误操作）
所有「更新数据」的操作（新增/编辑保存、删除、停单、充值、导入、重置密码、标记处理）均弹出通用确认框：
- 文案示例：「确认删除该记录？」「确认保存该订单？」
- 按钮：取消 / 确认；确认后执行原操作，取消则不执行。
- 停单、充值因语义独立，使用各自专属确认弹窗。

### 2.3 双击详情
- 客户列表双击 → 打开客户详情（同「详情」按钮）。
- 其余列表双击 → 打开「记录详情」弹窗，展示该行全部字段（键值对）。

### 2.4 Toast
- 操作结果用右下角 Toast 提示（保存/删除/导入/导出成功等），2 秒自动消失。

## 3. 登录页
- 元素：Logo（图片）+ 系统名同行、用户名、密码、登录按钮、演示账户快捷填充。
- 交互：点快捷账户填充用户名；登录失败 Toast 提示；成功进入工作台。

## 4. 工作台
- 指标卡：今日交付量、上游订单量、上游数据量、下游订单量、营业额、待处理预警。
- 图表区（落地用 ECharts）：近 7 天数据量柱状图、品类占比饼图、客户业务量排名、客户别利润雷达图。
- 快捷操作：新建提单、下发数据、查看预警。
- 处理逻辑：指标来自 `/api/dashboard/summary`；图表来自 `/api/dashboard/trend`、`/api/dashboard/rank`。

## 5. 订单管理

### 5.1 列表列（操作列在最前）
操作 | 状态 | 开始日期 | 截止日期 | 更新时间 | 订单号 | 上游 | 下游 | 渠道 | 任务名 | URL | 地区 | 数量 | 年龄上限 | 年龄下限 | PV | 创建时间

### 5.2 列交互
- **状态**：徽章（已提交=绿、在执中=蓝、已停单=琥珀）。
- **渠道**：可点击 → 弹出渠道详情（隶属关系 + URL 列表）。
- **URL**：显示一行（多 URL 显示「xxx 等N个」），点击 → URL 详情弹窗（列出全部 URL）。
- **地区**：显示一行摘要，点击 → 地区详情弹窗（省份/地市/排除省/排除市 四字段）。
- **操作**：`改`（改单）、`停`（停单），单字图标按钮，居中。

### 5.3 工具栏
- 查询条件（全字段，6 默认 + 更多）、⚙自定义表头、导出 Excel、**导出模版**、+新建提单。

### 5.4 新建提单 / 改单弹窗
字段：下游客户（下拉）、上游（下拉：新甲方/牛）、渠道（下拉）、任务名、URL 列表（多 URL，每 URL 带等级 高/中/低，可增删行）、数量、省份、地市、排除省份、排除地市、年龄下限、年龄上限、PV、开始日期、截止日期、停单日期（停单时填）、创建/更新时间（只读）。

**地区四字段联动规则**：
- 省份与地市互斥（不能同时有值）。
- 省份、地市、排除省份、排除地市 均支持多选，值以 `｜` 分隔。
- 省份选「全国」→ 可填排除省份（一个或多个）。
- 省份选「单个省」→ 可填排除地市（该省内城市）。

**处理逻辑**：
- 保存校验：下游/上游/渠道/任务名/数量必填；地区规则校验（省份地市互斥、全国/单省对应排除字段）。
- 保存后状态 =「已提交」；`updated_at` 置当前时间；新建时 `created_at` = 当前时间。
- 业务日期 +2 天后，系统定时任务将状态自动「已提交 → 在执中」。

### 5.5 停单弹窗
- 字段：停单原因（下拉：业务调整/数据质量不达标/合同到期/其他）、备注。
- 处理逻辑：确认后订单状态 =「已停单」、`stop_date` = 当前日期、`updated_at` 更新；生成一条「停单提醒」预警已处理记录。

## 6. 日活数据（数据管理 → 日活数据）
- 列：一级品类、二级品类、平台、渠道、手机号、姓名、来源(上游)、去向(下游)、任务、省份、地市、排除省份、排除地市、创建日期、洗名状态。
- 工具栏：查询条件（全字段）、⚙自定义表头、导出 Excel。
- 交互：双击行看详情；洗名状态为徽章（已洗名=绿、只分=灰、未命中=琥珀）。

---

## 7. 公积金（数据管理 → 公积金）
- 列（17 项）：手机号、姓名、身份证号、性别、省份、地市、单位名称、单位性质、缴存基数、缴存比例、月缴存额、账户余额、缴存状态、开户日期、缴至年月、运营商、来源文件。
- 工具栏：查询条件（性别/缴存状态下拉，其余文本）、⚙自定义表头、导入 Excel、导出 Excel、+新增。
- 操作列：编辑、删除（删除需确认）。
- 处理逻辑：导入 Excel 按模板解析，`(phone, source_file)` 唯一去重幂等；导出按当前筛选条件。

---

## 8. 客户管理

### 8.1 列表
- 列：客户编号、客户名称、类型、飞机账号ID、加工方式、余额、预警额度、备注、创建时间、更新时间、状态。
- 操作列：详情、充值、编辑。

### 8.2 客户详情弹窗（双击或「详情」）
- 上部：基本信息网格（客户编号/名称/类型/飞机账号ID/加工方式/是否记账/结算折扣/预警额度/总供货量/总销售额/总利润/余额/状态/备注/创建时间/更新时间）。
- 余额大字卡 + 预警额度。
- 下部 Tab：
  1. **订单记录**（默认）：字段对齐订单管理关键字段（订单号/状态/开始日期/截止日期/上游/渠道/任务名/URL/地区/数量）。
  2. 充值记录：日期/充值(U)/折算RMB/备注。
  3. 收货记录（下游）/供货记录（上游）。
  4. **单价管理**：数据来源于渠道表，逐渠道输入单价，保存写 `customer_price`。

### 8.3 充值弹窗
- 字段：充值金额(U)、折算 RMB（=U×汇率，自动）、充值日期、备注。
- 处理逻辑：确认后写 `customer_recharge`，更新客户 `balance`。

### 8.4 编辑/新增客户弹窗
- 字段：客户编号、客户名称、客户类型（上游/下游）、飞机账号ID、账单预警额度、加工方式、是否记账、状态、备注。
- 处理逻辑：保存需确认；校验编号唯一。

---

## 9. 配件管理（URL 列表）
- 列：归属、一级品类、二级品类、渠道、URL、等级、更新时间。
- 工具栏：查询条件、⚙自定义表头、+新增 URL。
- 操作列：编辑、删除（确认）。
- 新增/编辑弹窗：归属、一级品类、二级品类、渠道 + **URL 列表（多行，每行 URL + 等级 高/中/低，可增删行）**。
- 处理逻辑：保存校验至少 1 个 URL；每个 URL 独立写 `url` 记录；等级徽章（高=绿、中=琥珀、低=灰）。

---

## 10. 品类管理（一级/二级父子）
- 列表：一级品类行 + 缩进的二级品类子行（`└ 名称`），标注层级。
- 操作列：一级品类可「编辑/删除/+二级」；二级品类可「编辑/删除」。
- 处理逻辑：新增一级品类 → `category(level=1, parent_id=NULL)`；新增二级品类 → `category(level=2, parent_id=该一级)`；删除需确认，且有子品类时不可删。

---

## 11. 渠道管理
- 列：渠道名、状态。
- 工具栏：查询、⚙自定义表头、+新增渠道。
- 操作列：编辑、删除（确认）。
- 处理逻辑：渠道名唯一。

---

## 12. 运营商管理
- 列：运营商组合、状态。
- 数据：移动、联通、电信，及三者自由组合（移动+联通、移动+电信、联通+电信、移动+联通+电信）。
- 操作：新增、编辑、删除（确认）。

---

## 13. 账单管理
- 列：客户、业务日期、进货量、销售金额、余额、利润、创建日期。
- 交互：**客户名可点击** → 打开客户详情弹窗。
- 工具栏：查询、⚙自定义表头、导出账单、对账报告。

---

## 14. 预警中心
- 列：级别、类型、客户名、任务名、内容、触发时间、状态。
- 操作列：处理（确认后状态=已处理）。
- 处理逻辑：**停单提醒仅当停单日到达当日触发**；账单预警当余额低于客户预警额度触发。

---

## 15. 账户管理（仅 admin）
- 列：用户名、昵称、角色、状态、最后登录。
- 操作列：编辑、重置密码（确认）。
- 工具栏：⚙自定义表头、+新增账户、角色管理。
- 新增账户弹窗：用户名、昵称、角色（运营/财务/只读）、初始密码。

---

## 16. 权限说明
- admin（超级管理员）：全部权限，含账户维护。
- lemon001 / lemon002（运营）：业务全部权限，无账户查看/维护权限（前端隐藏 + 后端拦截）。
