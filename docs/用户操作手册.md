# LM 订单管理系统 · 用户操作手册

> 版本：2026-10 ｜ 适用对象：管理员、运营、财务、只读用户

LM 订单管理系统是一套覆盖「订单提单 → 数据分发 → 客户账单 → 洗名/查重」全流程的管理系统。左侧为功能导航，右上角为 AI 助手（悬浮按钮），底部显示当前登录用户与退出按钮。

## 3. 订单管理

![订单管理](screenshots/orders.png)

核心页面，负责订单的「新建、提单、改单、停单、复提、导入导出、验重」。

### 顶部筛选区

| 按钮 | 操作说明 |
|---|---|
| **查询** | 按上方筛选条件（状态/更新日期/甲方/订单号/工单号/代理/平台/小组/出数模版/是否加名/是否撞库等）过滤列表 |
| **重置** | 清空全部筛选条件并刷新 |
| 折叠图标 ▲/▼ | 展开/收起筛选条件行 |

### 工具栏按钮

| 按钮 | 操作说明 |
|---|---|
| **+ 新建提单** | 打开新建订单表单，填写必填项（更新日期/任务名/数量/开始日期/截止日期/上游/一级代理）后保存，状态为「未提」 |
| **导入订单** | 上传 Excel/CSV 批量导入订单；按「订单号」匹配更新，无订单号则新增 |
| **导入回执** | 上传回执文件，按「甲方+任务名」匹配订单并回填工单号 |
| **生成提单表** | 按「更新日期」筛选的未提订单，用提单模版生成提单表文件 |
| **提单确认** | 选择提单日期，将「未提/改单」订单变为「在执」，「待停」变为「已停」，并生成提单历史 |
| **订单验重** | 校验「在执」订单，运营商+URL集合+地区集合完全一致即标记为重复（写入重复订单字段） |
| **导出订单** | 按当前筛选条件导出订单（MB-019 模版格式） |
| **导出模版** | 下载订单导入/导出的 MB-019 模版文件 |
| **批量停单**（勾选后） | 选中订单批量停单，需选「更新日期+停单原因」，状态变为「待停」 |
| **批量删除**（勾选后） | 删除选中订单（不可恢复） |
| **批量复提**（勾选后，仅管理员） | 选中「已停」订单改回「未提」，需选「更新日期」 |
| **批量修改小组**（勾选后） | 批量修改选中订单的「小组」名 |
| 自定义表头图标 | 勾选要显示的列 |

### 行内操作图标

| 图标 | 说明 |
|---|---|
| ✏️ 编辑（蓝色） | 仅「未提」订单，直接编辑 |
| 改单（紫色） | 「在执/已停/改单」订单修改（渠道/运营商不可改，仅 URL/数量/地区等变化算改单） |
| 停单（橙色） | 「在执/改单」订单停单 |
| 🗑 删除（红色） | 删除该订单 |
| 双击行 | 打开订单详情弹窗 |

> 说明：甲方为「新」的订单，新建/更新/导入时若工单号为空，会按规则自动生成工单号（106→`147-kz-...`、小程序→`147-xcx-...`、dpi 按运营商与地区生成）；甲方为「牛」则保持不变。

## 5. 日活数据

![日活数据](screenshots/daily.png)

每日采集的数据明细，按「数据日期」组织，是分发/洗名/查重的数据源。

| 按钮 | 操作说明 |
|---|---|
| **查询 / 重置** | 按数据日期/甲方/任务id/任务名/手机号/省市/运营商/品类/代理等筛选 |
| **导出 Excel** | 导出当前筛选结果 |
| **① 导入日活** | 选择数据日期，上传 zip/Excel 导入（自动按「日期+任务id+手机号」去重） |
| **导入CSV**（管理员） | 上传结构化 CSV 原样导入 |
| **② 导出洗名** | 选择日期，导出「姓名为空且订单加名=是」的手机号 |
| **③ 导入洗名** | 上传洗名结果文件，按手机号回填姓名（同时同步洗名库） |
| **④ 分发数据** | 选择日期，按订单小组用出数模版生成文件打包下载，同时生成各代理账单 |
| **工单检查** | 统计所有「在执」工单在所选日期的数据量（降序），可导出 |
| **补充品类** | 按「平台→品类」映射补齐缺失的一级/二级品类 |
| **按日期删除**（管理员） | 删除所选日期下的全部日活数据 |
| **批量删除**（管理员，勾选后） | 删除勾选的行 |
